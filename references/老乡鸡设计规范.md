# 老乡鸡设计规范（精简版）

本文件用于 AI 生成老乡鸡品牌视觉时的核心规范速查。

## 品牌气质

亲切、朴实、热乎、有烟火气。中国本土餐饮感，偏日常、安心、接地气。

**禁止方向：** 赛博科技、奢侈品感、潮酷暗黑、过度AI味、荧光色、假食物照片。

## 品牌色彩

| 名称 | HEX | 用途 |
|------|-----|------|
| 品牌绿 | `#008042` | 主色，核心识别 |
| 品牌深色 | `#231815` | 文字、线条 |
| 卡其色 | `#BFB08F` | 辅助色 |
| 暖灰色 | `#E9DBCC` | 背景、底色 |
| 冷灰色 | `#EFEFEF` | 浅底、分隔 |
| 咯咯鸡身体 | `#FFC520` | IP主色 |
| 咯咯鸡鸡冠 | `#E43828` | IP点缀 |
| 咯咯鸡嘴尾 | `#FF8A00` | IP辅助 |

**配色规则：**
- 画面以品牌绿为主识别色
- 大面积底色适合品牌绿、暖灰、冷灰、米色
- 色彩偏温暖自然，避免荧光、霓虹、赛博紫蓝

## 字体

- 中文：**思源黑体**（标题 Heavy/Bold，正文 Medium/Regular）
- 英文数字：**TRY Grtsk Tera**
- 替代方向：厚重、方正、清晰、无衬线
- 禁止：书法体、手写体、花体、过细字体

## IP 角色

- **抱鸡场长**：草帽、蓝色上衣、绿色背带裤、亲切笑容
- **咯咯鸡**：暖黄身体、爱心鸡冠、橙色嘴尾
- 不得改变比例、轮廓、颜色和气质
- 使用时优先引用官方素材，不可AI重绘

## logo 使用

- 传播优先使用彩色标准版
- 深底用反白版，单色用黑色版
- 只能等比缩放，不可变形、切割、遮挡、变色
- 必须引用官方素材，不可AI自行重绘

## 出图自检

交付前检查：
- [ ] 一眼能看出是老乡鸡？
- [ ] 品牌绿、字体、logo、IP 是否符合规范？
- [ ] 画面主次清晰，不是信息和装饰平均用力？
- [ ] 手机端缩小后标题和数据仍可读？
- [ ] 像品牌方可发布的物料，不是AI概念图？
